# security-incident-response

Post-incident handling (NIST CSF simplified: detect / triage / contain / eradicate / recover / postmortem). For actual or suspected security breaches, regardless of trigger source (monitoring alert, user report, third-party CVE).

**Output path**: `docs/incidents/<incident-id>/`
- `incident.md` — incident timeline + triage
- `postmortem.md` — blameless postmortem
- `closed.json` — closed-state machine-readable record

**Skill**: `skills/extra/security-incident-response/SKILL.md`
