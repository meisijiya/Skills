# verify-chain

3-role article fact-check pipeline (Critic → Verifier × N → Repairer). Catches factual errors in technical articles against authoritative web sources before publication.

**Output path**: `docs/verification/<article-slug>/`
- `article-verified.md` — verified article
- `verification-report.md` — fact-check report

**Skill**: `skills/extra/verify-chain/SKILL.md`
