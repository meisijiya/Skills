# security-ownership-map

Git history people↔file security-ownership topology. Surfaces orphan sensitive code, hidden owners, bus-factor hotspots, and maintainer concentration from git history.

**Output path**: `docs/ownership-map/<repo-hash>-<date>/`
- `ownership-map.yaml` — input config (user-editable)
- `ownership-map.md` — main report
- `ownership-map.csv` / `ownership-map.json` — machine-readable

**Skill**: `skills/extra/security-ownership-map/SKILL.md`
