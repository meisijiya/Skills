# designer-handoff

Designer → engineer UI/UX spec handoff. Uses `ui-ux-pro-max-cli` reasoning engine (161 industry rules / 84 styles / 192 palettes / 74 font pairings / 22 frameworks) to generate design specs for designer-class agents.

**Output path**: `docs/design-spec/<plan-slug>/spec.md`

**Skill**: `skills/extra/designer-handoff/SKILL.md`

**Requires**: `ui-ux-pro-max-cli` installed globally (`npm i -g ui-ux-pro-max-cli`).
