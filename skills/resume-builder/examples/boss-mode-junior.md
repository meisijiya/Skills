# 应届生案例:没大厂实习,怎么写酥神简历?

> 应届生的核心困境:没经历 = 没素材。酥神方法论的回答:**把「校园项目」「开源」「比赛」当成经历来写**,外部认可不一定来自大厂。

---

## 原始素材(很普通)

```
求职方向:Java 后端
教育:XX 大学 计算机科学与技术 2022-2026
实习:无
项目:
- 课程设计:图书馆管理系统
- 毕业设计:基于 Spring Boot 的校园二手交易平台
- 学过 Redis、MySQL、Spring Boot
比赛:蓝桥杯省三等奖
开源:无
```

## 体检报告

| 军规 | 结果 | 说明 |
|------|------|------|
| 1 Owner | ⚠️ | 课程设计可包装为 owner,但不是 0→1 的「产品」 |
| 2 0→1 | ✅ | 项目从零搭建,可写 0→1 |
| 3 外部认可 | ⚠️ | 只有蓝桥杯,太弱 |
| 6 数据 | ❌ | 无任何数字 |
| 7 岗位词 | ⚠️ | 有 Spring Boot,缺高并发类词(但没做过不能编) |

## 关键决策

1. **不能编造**大厂实习——但可以**放大真实事实**:
   - 图书馆管理系统 → 用户真实使用(班级/宿舍在用)→ 有真实用户 = 外部认可
   - 二手交易平台 → 上架到 GitHub + 部署上线 → 有链接 = 外部认可
2. **补外部认可**(真实可操作):
   - 把二手交易平台部署上线,README 写好,发到技术社区
   - 参加一次线上黑客松(如 AdventurerX / 科大讯飞 / 字节青训营)
   - 写 2-3 篇技术博客(掘金/CSDN),获得阅读量
3. **蓝桥杯省三**:不写「省三等奖」单薄,写成「蓝桥杯省赛三等奖(全省 top 30%)」——如果有这个比例的话,没有就不要加,诚实。

## 应届生军规补充

1. **真实用户 > 高大上技术**:校园项目被同学真实使用,比「模仿 xx 系统的课程设计」值钱
2. **「部署上线」是免费的加分项**:GitHub 链接 + 在线演示 = 可验证的证据
3. **用比赛/博客补外部认可**:蓝桥杯、黑客松、技术博客阅读量,都是「外部认可」
4. **诚实边界不破**:没做过的并发、高可用,一个词都不能写——面试深挖必穿

## 金句

> 应届生不是没有经历,是没把经历翻译成证据。
> 你 0→1 搭的「校园二手平台」,和 0→1 搭的「电商中台」,在方法论上是一样的——区别只在规模,不在能力。
