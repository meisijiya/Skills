# 求职信模板(酥神 style)

> 简历方法论同样适用于求职信。核心原则不变:**不自我评价,用外部认可当证据;先抬对方,再落自己。**

---

## 模板

```
尊敬的 [HR/负责人] 您好:

我在 [渠道] 看到贵司 [岗位名] 的招聘信息。
我关注 [公司/团队] 很久了——[一句话说清你为什么认这家公司,
最好是具体业务/产品,不要「贵司是行业巨头」这种废话]。

简单介绍一下我的核心资产:

[外部认可 1]——[一句话证明,比如:Apache Fory Committer,字节排序第一开源项目 Owner,★ 7.6k]
[外部认可 2]——[一句话,比如:主导 0→1 项目 XXX,数据 XX]
[岗位相关证据]——[把你和目标岗位最匹配的一段经历,一句话点出]

为什么是我:我做过 [岗位核心要求对应的具体事],在 [关键场景]
里有 [数据] 的成绩。我可以在这份岗位的第一天就 [落地价值,一句话]。

附件是我的简历(一份 PDF),欢迎随时联系我面试。
期待与您交流。

[姓名] · [电话] · [邮箱] · [GitHub/作品链接]
```

## 示例(AI 应用工程师)

```
尊敬的 HR 您好:

我在内推渠道看到字节跳动「AI 应用工程师」的招聘信息。
我关注抖音 AI 基建团队很久了——你们在 Agent 训练数据流水线
上的投入,和我的积累方向完全一致。

简单介绍一下我的核心资产:

Apache Fory Committer,ByteDance/Deer-Flow Maintainer(★ 7.6k)
主导 0→1 搭建 Long-Horizon Agent Harness 2.0(字节排序第一开源)
构建 Agent 评测流水线,覆盖 SWE 系列 Benchmark,测试集通过率 +25%

为什么是我:我做过 Agent 评测与 SFT/RL 数据生产全链路,
在抖音 AI 基建实习期间拿到 L1 奖赏。我可以在这份岗位的
第一天就上手评测体系设计与数据管道优化。

附件是我的简历(一份 PDF),欢迎随时联系我面试。
期待与您交流。

LoFiSu · 138-xxxx-xxxx · xxx@gmail.com · github.com/LoFiSu
```

---

## 求职信 3 条军规

1. **第一段必须有「具体」**:你认的是对方的哪件事,写出来。「关注贵司很久」= 没写。
2. **中间段全是证据**:外部认可 + 数据,一条自我评价都不允许。
3. **结尾给「落地价值」**:不要「希望能获得这次机会」,要「我能第一天就带来 XX」。

## 反例(自杀版)

```
尊敬的 HR 您好:

我叫 XX,毕业于 XX 大学,专业是 XX。我性格开朗、学习能力强、
抗压能力好,热爱互联网行业。我相信凭借我的努力和热情,
一定能为贵司创造价值。希望您能给我一个机会。

此致敬礼
XX
```

> ❌ 全文没有一条证据、没有一家具体公司、没有任何数据——HR 十秒删除。

## 中英求职信要点

### 中文版

- 称呼:「尊敬的 HR / 负责人 / 团队 Lead 您好」(知道名字更好)
- 落款:「期待与您交流」+ 姓名 + 联系方式
- 不写「此致敬礼」(过于正式/老派)

### 英文版

- Subject line: `Application for {{岗位}} - {{姓名}}`
- 称呼: `Hi {{名字}},` 或 `Dear Hiring Team,`
- 落款: `Best regards,` + 姓名 + LinkedIn / GitHub
- 长度: 严格 200-300 字,超过 400 字 HR 不会读

---

## 何时写求职信

| 情况 | 是否必写 |
|------|---------|
| 内推渠道,内推人帮你转交 | **强烈建议**(内推人会看你写的内容) |
| 主动投递官网 | 选写(HR 一天看几百封,求职信关注度低) |
| 海投(招聘平台一键投递) | 不写 |
| 邮件 cold email 给团队 Lead | **必写**(这是你和团队 Lead 唯一的对话窗口) |
