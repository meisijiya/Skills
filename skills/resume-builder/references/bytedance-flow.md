# 字节简历 / 面试 / 投递经验

> 来自酥神方法论的真实战场:从 0 offer 到字节多段实习 offer 的经验沉淀。专攻字节投递/面试时读这份,其他大厂类似。

---

## 一、简历阶段

### 1. 一屏法则

字节 HR 一天筛几百份简历。你的头衔、最高认可、最强项目必须在**第一屏**内出现。

反面教材:把「字节排序第一开源项目 Owner」写在第二页——HR 根本没翻到第二页。

### 2. 关键词对表

对着 JD 改简历:JD 里出现的技术词,必须出现在简历里(做过才写)。

反面教材:投「AI 应用工程师」却通篇写「电商运营」——ATS 第一轮就被筛。

### 3. 外部认可置顶

开源贡献、Star 数、奖项、技术文章——这些是简历的「信用分」,置顶放。

反面教材:把「学习能力强」写在最上面——这句话的信用分是 0。

### 4. 一页原则

应届/实习简历**必须一页**。多页 = 不会取舍。

反面教材:把 8 个「参与」项目全列上,一页半——全是噪音。

---

## 二、面试阶段

### 1. 简历即面试提纲

你写进简历的每个「0→1」「Owner」都要经得起深挖。面试官最爱问:

- 「这个项目架构怎么设计的?为什么这么选?遇到什么坑?」
- 「这个 25% 怎么测的?baseline 是什么?」

反面教材:简历写「主导架构升级」,面试时说不清旧架构和新架构的差异——当场露馅。

### 2. STAR 答法

每个项目按 **Situation(背景) → Task(任务) → Action(行动) → Result(结果)** 回答,和军规 5 的 Before → After 是同构的。

反面教材:只讲「我做了什么」,不讲「为什么这么做」「效果如何」。

### 3. 数据要滚瓜烂熟

「通过率 +25%」「耗时从 90s 压到 <20s」——面试官会追问数据怎么算的。答不上来 = 简历造假嫌疑。

反面教材:简历写「性能提升 30%」,面试问「怎么测的?基线是什么?」答不出来。

### 4. 少说「参与」,多说「决定」

「我参与了这个项目」→「这个模块的架构是我定的,因为……」

反面教材:全程「我们团队做了……」——面试官无法评估「你」的贡献。

## 三、投递阶段

### 1. 多渠道并行

官网投递 + 内推 + 招聘软件 + 实习群,全开。大厂内推**优先处理**(HR 会优先看内推简历)。

反面教材:只投官网,简历躺在池子里一个月无人问津。

### 2. 同一岗位只投一次

重复投递会降低权重。投之前确认简历已针对该岗位定制过。

反面教材:同一份简历一键投 50 个岗位——被标记为「海投党」。

### 3. 跟进要有节奏

- 投递 5-7 天无回复 → 礼貌跟进一次(给内推人留言)
- 面试后 3-5 天无消息 → 跟进一次
- 不要一天三问

反面教材:面试完第二天就追问结果——显得焦虑,也占用面试官时间。

### 4. 内推话术

```
Hi [内推人],我是 [姓名],目前 [年级/学校],看到你发的 [岗位] 链接很感兴趣。
我对 [岗位要求的一个具体技术点] 有过 [简短经历 / 数据]。
附件是我的简历(已针对岗位定制),如果有合适的机会,麻烦帮忙推进,感谢!
```

---

## 四、反面教材合集(简历「自杀」清单)

- 简历标题写「我的简历.pdf」
- 文件名 `未命名文档(3).pdf`
- 自我评价 200 字小作文
- 错别字、标点中英混用
- 照片模糊或证件照风格突兀
- 经历时间混乱(2025.05-2026.05 写错为 2025.5-2026.5)
- 联系方式缺失或写错
- 一份简历投所有岗位

---

## 五、金句

> 简历不是写给「未来的自己」看的,是写给「15 秒后的 HR」看的。
> 你能把简历写成什么样,决定你被什么级别的面试官看到。
> 酥神简历的终极目标:让 HR 看完第一屏,就忍不住翻第二屏。
